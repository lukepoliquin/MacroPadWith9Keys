# MacroPadWith9Keys
My Macropad has 9 keys(10 if you include the rotary motor), and and OLED display
it will be using the KMK firmware. 
my case was designed in Fusion360 and it includes 4 holes for screws and heatset inserts.
I havent decided on what to do with the oled screen yet.
it uses a matrix to connect all the switches to the microcontroller.
it uses the XIAO SEEEDUINO microcontroller.
